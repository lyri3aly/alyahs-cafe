my projects

rhythm crossing

Rhythm Crossing is an interactive rhythm game inspired by the popular VR game Beat Saber. It runs by connecting a phone (as the console) to a laptop and utilizing it’s IMU sensors. This project was built during JamHacks 10, the first hackathon I attended. This was also was my first time working with concepts such as using the browser's DeviceMotionEvent / DeviceOrientationEvent APIs.

academica

Academica is a student life planner and dashboard that connects the ideas from popular tools such as Notion, Google Calendar, todoist, Flocus, lifeat, Motion, and Reclaim AI into an all-in-one productivity tool. This tool interconnects smart AI calendar scheduling, study routines, pomodoro timers, and much more to be personalized to every user. This web app is a current work in progress.
